# E2E testning med Playwright

Starta projekt

```bash
# skapa mapp för projektet
mkdir my-project
cd my-project/

git init
# Skapa .gitignore

npm init -y
# Lägg till "type": "module" i package.json

npm create playwright@latest
# Välj: JavaScript, tests, Y, Y

# Skapa test-skript i package.json
# Starta ditt test-skript
npm run test-e2e
```
